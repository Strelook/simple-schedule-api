# Simple Schedule API

API для управления и вывода школьного расписания конкретного класса. Служба автоматически объединяет базовый недельный шаблон и точечные замены (исключения) на конкретные даты.

## 🚀 Возможности

- 📅 Расписание на текущий день, текущую и следующую неделю
- 🔁 Расписание на N дней вперёд
- 🗂️ Управление базовым недельным шаблоном (Пн–Вс)
- 🔄 Замены и исключения на конкретные даты (включая отмену уроков)
- 🛡️ Авторизация через HTTP-заголовок `X-API-Key`

## 🛠️ Стек технологий

- [FastAPI](https://fastapi.tiangolo.com/) — веб-фреймворк
- [SQLAlchemy](https://www.sqlalchemy.org/) — ORM
- [SQLite](https://www.sqlite.org/) — база данных (по умолчанию)
- [Pydantic Settings](https://docs.pydantic.dev/latest/concepts/pydantic_settings/) — конфигурация

## 📦 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Strelook/simple-schedule-api.git
cd simple-schedule-api
```

### 2. Создание виртуального окружения и установка зависимостей

```bash
python -m venv venv
source venv/bin/activate        # Linux / macOS
# venv\Scripts\activate        # Windows

pip install -r requirements.txt
```

### 3. Настройка окружения

Скопируйте шаблон конфигурации и укажите свои значения:

```bash
cp .env.example .env
```

| Переменная      | Описание                                                        |
|-----------------|-----------------------------------------------------------------|
| `PROJECT_NAME`  | Название проекта (отображается в заголовке API)                 |
| `DATABASE_URL`  | Строка подключения к БД (по умолчанию SQLite)                   |
| `X_API_KEY`     | Секретный ключ для авторизации через заголовок `X-API-Key`      |

### 4. Запуск сервера

```bash
uvicorn app.main:app --reload
```

Документация API будет доступна по адресу: <http://127.0.0.1:8000/docs>

### 5. Наполнение базы тестовыми данными (опционально)

```bash
python seed.py
```

## 🔐 Авторизация

Для доступа ко всем эндпоинтам необходимо передавать HTTP-заголовок:

```
X-API-Key: ваш-секретный-ключ
```

## 📚 Эндпоинты

Все эндпоинты имеют префикс `/schedule`.

### Расписание

| Метод | Путь                          | Описание                                        |
|-------|-------------------------------|-------------------------------------------------|
| GET   | `/schedule/today`             | Расписание на текущий день                      |
| GET   | `/schedule/current-week`      | Расписание на текущую неделю (Пн–Вс)            |
| GET   | `/schedule/next-week`         | Расписание на следующую неделю (Пн–Вс)          |
| GET   | `/schedule/today-plus-days/{days_count}` | Расписание на N дней вперёд          |

### Управление шаблоном

| Метод | Путь                  | Описание                                        |
|-------|-----------------------|-------------------------------------------------|
| GET   | `/schedule/template`  | Получить базовый недельный шаблон               |
| POST  | `/schedule/template`  | Полностью перезаписать базовый шаблон           |

### Замены и исключения

| Метод | Путь                        | Описание                                        |
|-------|-----------------------------|-------------------------------------------------|
| GET   | `/schedule/exceptions/{date}` | Получить замены на конкретную дату            |
| POST  | `/schedule/exceptions`      | Добавить/обновить замены на дату                |

> **Примечание:** чтобы отменить урок, передайте в поле `subject` строку `"Отмена"`.
